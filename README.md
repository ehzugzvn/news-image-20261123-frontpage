# FRONTPAGE — Monday 23 November 2026

A classic broadsheet front page that sums up one day's world news — Monday 23 November 2026 — in a single 1024×1024 image: four illustrated leads (COP31 collapse, the Benghazi corvette sinking, the Dymer rescue, and the US House result), ten tier-2 stories with pictograms around a pinned world map, a UTC timeline, the day in numbers, and 21 large-type briefs, all date-checked against older news.

Bounty: https://make.fun/bounty/news-image-20261123

## How to run

- `python3 main.py` — copies `entry.png` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
- `python3 render.py` — regenerates `entry.png` from the drawing code (requires Pillow and the fonts in `fonts/`).
